# SeeMind v0.66.7 — Capability Intelligence & Best Specialist Selection

SeeMind does not ask “which AI brand is best?” It asks “which capability is required to resolve the remaining problem?” Providers are replaceable implementations of capabilities.

## Rules
1. Select capability, not brand.
2. Local Student owns perception/context/evidence; external specialists fill residual gaps.
3. Current facts prefer current-data/search capabilities; official facts prefer official-source retrieval; visual residuals prefer visual reasoning; complex reasoning prefers frontier reasoning.
4. Provider ranking uses capability fit plus measured task success, reliability, evidence quality, latency and cost.
5. A famous or generally strong provider gets no universal priority.
6. Provider performance may evolve; routing should learn from real task outcomes without rewriting product logic.
7. Specialist output remains evidence/candidate input and must pass existing verification policy.
