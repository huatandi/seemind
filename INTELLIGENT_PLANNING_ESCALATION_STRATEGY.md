# SeeMind v0.67.2 — Intelligent Planning Escalation

SeeMind does not need to become a frontier-scale universal model merely to decide which specialists to use. When decomposition itself is genuinely complex, SeeMind may request the provider-neutral capability `complex_problem_decomposition`.

Simple problems remain local. Planning escalation is reserved for multi-intent, dependency-rich, multi-residual, or low-confidence decomposition.

The planning specialist is advisory only. It cannot select a vendor, execute tools, override safety/privacy, or declare the problem resolved. It proposes a bounded task graph; SeeMind validates dependencies, cycles, completed-work duplication, capabilities and job count before execution.

**The master advises; SeeMind keeps command authority.**
