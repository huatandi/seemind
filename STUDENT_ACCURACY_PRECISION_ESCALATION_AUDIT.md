# SeeMind v0.66.4 — Student Accuracy Maximization & Precision Teacher Escalation

## Strategic priority
Accuracy first. Modern phones are treated as sufficient for meaningful local Student perception. Local evidence should be exhausted when useful, but uncertainty must never be converted into fact.

## Residual escalation
The Student now describes the unresolved slice: missing fields, uncertain fields, conflicts, candidate hypotheses, and an optional ROI. Reliable Student work is explicitly preserved. A Teacher is asked to solve only the residual gap.

## Teacher authority boundary
Teacher output is candidate evidence, not truth. It must return through the existing Verification Core before presentation. Conflicting evidence remains conflict; it is not averaged into confidence.

## Privacy and efficiency
The minimum-necessary package carries the residual goal and bounded focus metadata. Existing visual packaging continues to prefer ROI media when supplied and requires image consent.

## Non-goals
This release does not add a second router, a Teacher brain, or aggressive memory optimization. Runtime efficiency remains guarded, but recognition accuracy and calibrated uncertainty have higher priority.
